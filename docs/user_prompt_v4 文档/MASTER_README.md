**A**: 取决于你的目标

| 刚开始学习量化交易 | V2 |

### Q2: V2和V3可以同时用吗？

**A**: 可以！推荐混合使用

## 🎯 核心设计原则

### V2的原则

```
1. 标准指标（EMA/RSI/MACD等）→ 不需要说明
2. 自定义指标 → System Prompt中定义 + 数据中加标签
3. 人类可读优先
```

### V3的原则

```
1. 所有指标纯数值化（无分类标签）
2. 提供明确的数学组合公式
3. 模型优化优先
4. 强化学习友好
```
