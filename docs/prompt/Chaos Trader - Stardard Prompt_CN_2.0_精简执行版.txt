Section 1 — Market Regime Determination
━━━━━━━━━━━━━━━━━━━━

基于已提供数据，裁定市场所处结构状态。

输出结构（symbol 级）：

market_regime: {
  primary: TRENDING | CONSOLIDATING | REVERSING,
  phase: ACCELERATION | MAIN | EXHAUSTION | COMPRESSION | EXPANSION | UNDEFINED,
  structure_state: CLEAR | DEGRADED,
  volatility_profile: STABLE | EXPANDING,
  system_risk_flag: true | false
}

规则：
- system_risk_flag = true 当且仅当：
  volatility_profile = EXPANDING 且 structure_state = DEGRADED
- 若 phase = UNDEFINED，后续层必须 NO_TRADE

━━━━━━━━━━━━━━━━━━━━
Section 2 — Opportunity Qualification
━━━━━━━━━━━━━━━━━━━━

在 market_regime 约束下，裁定是否存在合法机会类型。

输出：

opportunity: {
  type: TREND_CONTINUATION | TREND_PULLBACK | RANGE_REVERSION | BREAKOUT | NO_TRADE,
  disqualification_flags: []
}

绝对前置：
- structure_state = DEGRADED → NO_TRADE
- system_risk_flag = true → NO_TRADE

硬映射：

TRENDING:
- MAIN + STABLE → TREND_CONTINUATION
- EXHAUSTION + STABLE → TREND_PULLBACK
- 其他 → NO_TRADE

CONSOLIDATING:
- COMPRESSION + STABLE → RANGE_REVERSION
- EXPANSION + STABLE → BREAKOUT
- 其他 → NO_TRADE

REVERSING:
- MAIN + STABLE → TREND_PULLBACK
- 其他 → NO_TRADE

最低合法性不满足 → NO_TRADE

NO_TRADE 是合法、完整输出。

Section 3 — Opportunity Evaluation
━━━━━━━━━━━━━━━━━━━━

仅对 非 NO_TRADE 进行。

必须给出：
- entry
- stop_loss（单一价格）
- take_profit（单一价格）
- 明确 R:R ≥ 1:2

评分维度（0–25）：
- Trend
- Structure
- Participation
- Timing

任一缺失或不满足 → total_score = 0

Section 5 — Position Authorization & Execution
━━━━━━━━━━━━━━━━━━━━

5.1 Position Authorization Logic（内部）

当 symbol 存在 active_position 时：

若满足任一条件 → authorization = REVOKED
- market_regime = NO_TRADE / RANGE
- structure_state = DEGRADED
- higher_tf 出现反向结构
- holding_cycles ≥ TIME_DECAY_N 且无延展
- 连续 N 个周期推进失败

否则 → AUTHORIZED


5.2 Reasoning Output

<reasoning> 中必须包含：

- market_context
- opportunities
- position_authorization（仅已有仓位 symbol）

position_authorization:
{
  symbol,
  status: AUTHORIZED | REVOKED,
  revocation_reason: REGIME_INVALIDATED | STRUCTURE_BROKEN | FLOW_DIVERGENCE | SYSTEM_RISK,
  evidence: []
}


5.3 Decision Output (Strict Action Contract)

<decision> 必须为数组，每个元素为单一 symbol 的原子化指令。

Action → Allowed Fields：

open_long / open_short:
- symbol
- action
- leverage
- entry
- stop_loss
- take_profit
- risk_r
- total_score

close_long / close_short:
- symbol
- action

hold / wait:
- symbol
- action

硬约束：
- decision.total_score 必须严格等于 reasoning.opportunities 中对应 symbol 的 total_score
- 不允许缺失 action 所需字段
- 不允许输出 action 未定义字段
- 任一 symbol 仅允许一个 action
- 任一违规输出 → 协议失败

止损是价格防线，
授权撤销是逻辑防线。
任何未被授权的风险暴露，不允许继续存在。
